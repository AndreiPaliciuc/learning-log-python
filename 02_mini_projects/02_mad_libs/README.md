# Mini-Project: Mad Libs

Dieses Mini-Projekt ist eine kleine Übung für:
- `input()` (Benutzereingaben)
- Strings und Textformatierung
- f-Strings (z. B. `f"Hello {name}"`)
- `.strip()` (entfernt Leerzeichnen am Anfang und Ende)

## Was macht das program?
Das program fragt den Benutzer nach Mehrere Wörtern (Adjektiv, Nomen, Verb, Ort, Promi) und baut daraus eine kurze Geschichte.

Abfrage:
- Adjektiv 1
- Adjektiv 2
- Nomen
- Verb
- Ort
- Promi (Celebrity)
