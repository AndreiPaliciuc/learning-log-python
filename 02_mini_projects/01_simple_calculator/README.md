# Mini-Projekt: Simple Calculator (Addition)

Dieses Mini-Projekt ist der erste kleine Schritt aus dem Kurs.  
Ziel ist es, Benutzereingaben zu lesen und in Zahlen umzuwandeln.

## Ziel
Eingaben vom Benutzer lesen un mit numerischen Datentypen arbeiten.

## Was macht das Programm?
- fragt zwei Zahlen ab
- wandelt beide Werte in `float` um
- gibt die Summe aus
