# Lektion: Listen - Grundlagen & Funktionen

In die 1te und 2te Lektion von Ornder (03_data_structures_and_flow) übe ich die Grundlagen und Funktionen von **Listen (lists)** in Python.

## Ziele
- eine Liste erstellen
- auf Elemente per Index zugreifen (`list[0]`, `list[-1]`)
- Elemente hinzufügen und entfernen
- `len()` benutzen
- Unterschied zwischen `sort()` und `sorted()` verstehen

## Was macht main.py?
- erstellt eine Mitarbeiterliste (Listen)
- zeigt Zugriff auf erstes und letztes Element
- nutzt `append()` und `insert()` zum Hinzufügen
- nutzt `remove()` und `pop()` zum Entfernen
- zeigt `len()` und `in`
- zeigt Sortieren mit `sorted()` (neue Liste) und `sort()` (ändert die Liste)
