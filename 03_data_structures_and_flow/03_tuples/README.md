# Lektion: Tuples (Python)

In dieser Lektion übe ich die Grundlagen von **Tuples** in Python.

## Ziele
- verstehen, was ein Tuple ist (geordnet, aber **unveränderlich**)
- Zugriff per Index (`tuple[0]`, `tuple[-1]`)
- Tuple Packing und Unpacking
- Unterschied zwischen `list` und `tuple`
- Umwandlung mit `list()` und `tuple()`

## Was macht `main.py`?
- erstellt Tuples (z. B. Koordinaten, Personendaten)
- zeigt Zugriff per Index
- zeigt Unpacking (`city, state = location`)
- zeigt einen typischen Use Case: feste Werte (z. B. Wochentage)
- zeigt Konvertierung zwischen Liste und Tuple
